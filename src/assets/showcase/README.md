# Showcase screenshots

Drop your website screenshots here to fill the "Examples" tabs on the Home page.

Name each file after its tab key:

- `landing.png` (or `.jpg` / `.webp`) — Landing page tab
- `business.png` — Business website tab
- `webapp.png` — Web app tab

They're picked up automatically (via `import.meta.glob` in `src/pages/Home.tsx`).
Until a matching file exists, the tab shows a "coming soon" placeholder.

Tip: a wide screenshot around 1600×1200 (4:3) looks best in the browser frame.
